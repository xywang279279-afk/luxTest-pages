What It Does

围绕孩子学习场景设计的首页

新版首页不只是显示瞬时数值，而是围绕“当前书桌是否适合学习”组织信息：先检测，再看统计，再给出等级和建议。

一键检测与重测

首页仪表盘提供“开始检测 / 检测中 / 重新检测”状态，检测时建议保持手机稳定 2-3 秒。

最低 / 最高 / 平均

每次采样会展示最低照度、最高照度和平均照度，并明确提示优先用平均照度判断。

四档学习照度等级

按平均照度分为需改善、基础达标、较优学习、明亮充足，并生成对应的结果解读和调整建议。

iPhone 估算详情

iPhone 可展开查看平滑近似 lx、即时近似 lx、置信度、稳定性、样本数、ISO 和 EV100。

本地记录与导出

停止采样后生成本地测试记录，可在导出页查看统计结果，并按单条导出 JSON 或 CSV。
